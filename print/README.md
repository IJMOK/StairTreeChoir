## Sliced for the P1S

`python -m tools.slice` (Bambu Studio's command line): printer Bambu Lab P1S 0.4 nozzle, filament Bambu PETG Basic @BBL X1C, process [bambu/stair-tree-mounts.json](bambu/stair-tree-mounts.json) (0.20mm Standard, 3 walls, 15% infill). Open the `.gcode.3mf` in Bambu Studio and send it; it's already sliced.
