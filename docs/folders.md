# Where things are

## This repo

"Generated" means `python -m tools.build` (or the named tool) writes it: change the input and rebuild, never edit it by hand.

| Folder | What's in it | Edited by |
|---|---|---|
| `CLAUDE.md`, `README.md` | Project brief and decisions; quick start | hand |
| `cad/` | CNC layout of one tree (`.svg`, `.dxf`) | generated (`tools/gen_cnc.py`) |
| `data/` | `blank.json` (tread outline), `sites.json`, `voices.json` | hand |
| | `tree-layout.json` | generated (`tools/tree_layout.py`) |
| | `xlights-effects.json` (effect settings keys) | generated (`tools/xl_keys.py` from the xLights source) |
| `data/songs/` | One arrangement per sequence: who sings each line, looks per section, paths to its show-folder files | hand; `skit-*.json` generated by `tools/skit.py` |
| `data/skits/` | Skit scripts (who says what) | hand |
| `docs/` | BOM, build guide, CNC cutting, test checklist, show night, research, notes | hand (`show-folder-moves.md` is a one-off log) |
| `electronics/` | Tree controller board and connections; site wiring | `README.md` hand; `connections.md`, `site-wiring.md`, `*.svg` generated |
| `enclosure/` | Tree and site boxes (OpenSCAD) and their STLs | `.scad` hand; `.stl` exported from them |
| `feet/` | The boots and peg (OpenSCAD), STLs, previews | `.scad` hand; `.stl`/`.png` exported |
| `fixtures/` | CNC hold-down clamp (OpenSCAD) and STLs | `.scad` hand; `.stl` exported |
| `fpp/` | Per-site FPP config: `site-x/` outputs, playlists, schedule | `README.md` hand; `site-*/` generated (`tools/gen_site_config.py`) |
| `photos/` | Photos of the treads, for measuring | as taken |
| `tests/` | pytest suite (`python -m pytest -q`) | hand |
| `tools/` | Every generator and helper (`python -m tools.<name>`) | hand |
| `wled/` | WLED config per tree, `stairtree-01..14.json` | `README.md` hand; configs generated |
| `xlights/` | `StairTree.xmodel` and the xLights notes | `.xmodel` generated (`tools/gen_xmodel.py`); `README.md` hand |

Not in git: `previews/` (GIFs from `tools/preview_render.py`), `.venv/`, and everything in the xLights show folder below (lyrics and audio are copyrighted).

## The xLights show folder (`Documents\xLights`)

**Naming rule:** every file of a song shares its sequence name, the name FPP's playlists use. Skits use their script name (`data/skits/<name>.json`). Paths in `data/songs/*.json` are relative to the show folder.

| Where | What |
|---|---|
| top level | Sequences: `<Sequence name>.xsq` (xLights) and `.fseq` (render, uploaded to FPP); xLights' own `.xbkp` backups beside them. xLights and FPP expect them here. Also the layout and controllers (`xlights_rgbeffects.xml`, `xlights_networks.xml`), `user_dictionary` (extra lip-sync words), `Background.jpg`. `tools.xsq` and `tools.xl_timing add` leave a `.xsq.bak` beside the sequence they edit; move old ones to `_Archive`. |
| `Audio\Songs\` | Per song: `<Sequence name>.mp3`, `.lyrics.txt`, `.lrc` (if LRCLIB had one), `.beats.json`, `.timing.json` (word timing for the xLights timing track). E.g. `Feliz Navidad.mp3` … `Feliz Navidad.timing.json` for `Feliz Navidad.xsq`. |
| `Audio\Skits\` | Per skit: `<name>.wav`, `.lyrics.txt`, `.beats.json`, `.timing.json`; sequence `Skit <name>`. `Goodnight` also uses `goodnight.*`. |
| `Audio\Loops\` | `Waiting.timing.json`, `Waiting.beats.json` (the Waiting loop has no audio). |
| `_Archive\` | Old test sequences, screenshots, old `.xsq.bak` copies. Nothing there is used. |
| `Voices\` | Piper voice models for the skits. |
| `RenderCache\`, `Backup\` | xLights' own caches and backups. |
| `palettes\`, `colorcurves\`, `valuecurves\` | xLights presets. |

Inside a sequence the timing tracks keep short names (`FelizNavidad`, `Skit_tuning_up`; `lyrics_track` in the arrangement), not the file names.

Old names before the 24 Oct 2026 tidy: [show-folder-moves.md](show-folder-moves.md).
