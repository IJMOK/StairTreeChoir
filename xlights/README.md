# xLights model

`StairTree.xmodel` is generated by `tools/gen_xmodel.py` from `data/tree-layout.json`. Don't edit it by hand; change the layout and run `python -m tools.build`.

## What's in it

- **Custom model**, 39 × 90 grid at 10mm per cell, so it has the tree's real proportions. Node numbers are in wiring order (1 = base-left, data in).
- **Face definition** "StairTree" (Node Ranges), so the Faces effect and lip-sync work straight away:

| Face key | Nodes | What lights |
|---|---|---|
| Mouth-rest, Mouth-MBP | 74-80 | lip line |
| Mouth-etc, -E, -FV, -L | 69-80 | lip + small arc |
| Mouth-AI | 60-68, 74-80 | lip + wide arc |
| Mouth-O, -U, -WQ | 60-73 | small + wide arcs |
| Eyes-Open | 81-92 | both hexagons |
| Eyes-Closed | 83-85, 89-91 | lower half of each eye (blink) |
| FaceOutline | 1-59 | tree outline |

  Custom colours are on: mouth red, eyes white, outline green. Turn "CustomColors" off in the face definition dialog to colour them from the effect palette instead.
- **Sub-models**: Outline, Mouth, Mouth Wide, Mouth Small, Lip, Eyes, Eye Right, Eye Left.

Format checked against the xLights source (commit 75c3e11, 20 Oct 2026). **Not yet tested in xLights itself**: the first import is the real check.

## Setting up the 6-tree layout

1. Use a show folder outside this repo (e.g. `Documents\xLights\StairTreeChoir`); xLights writes large render and backup files there.
2. On the Layout tab, import `StairTree.xmodel` with xLights' custom model import (Download/Import Models). Name it `Tree1`.
3. Check: 92 nodes; the face appears under the model's Faces; node 1 is bottom-left.
4. Copy and paste it to make `Tree2` … `Tree6` and space them out on the layout.
5. Channels (CLAUDE.md §2): slot s starts at channel (s-1) × 276 + 1, 276 channels each, so Tree1 = 1, Tree2 = 277, Tree3 = 553, Tree4 = 829, Tree5 = 1105, Tree6 = 1381.
6. For testing from the PC with the spare ESP32: add an Ethernet controller of protocol DDP at the ESP's IP, 276 channels, and assign `Tree1` to it. WLED on the ESP needs 92 LEDs and its realtime (DDP) receive enabled.
7. Make a group "All Trees" with Tree1–Tree6 for whole-show effects.

Later, the per-site FPP config (M5) sends each slot's channels to the right tree by IP.
