# Site wiring

Generated by tools/gen_site_wiring.py from data/sites.json; don't edit.

**Defaults, not yet confirmed by Rob:** tree counts per site and every run length. Edit data/sites.json and run `make all`.

Each site: Mean Well LPV-100-12 (8.5A, IP67) beside the site box, one per pair of trees; each tree on its own run from the site box, fused 5A where the run starts. The show player (Pi, sound card, PAM8610) runs off PSU 1 on its own 3A fuse. Loads are full white: 2.3A per tree, 1.5A for the player.

Mains never enters a printed box. Each PSU has its own mains lead to an RCD-protected outdoor socket (or a weatherproof multi-way box on one).
